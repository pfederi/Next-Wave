# App Store Connect — Texts for v3.8.0

## What's New (English)

Wave Check-in is here! 🤙

See who's riding each wave — and let the crew know you're coming.

• Tap the check-in badge on any upcoming wave to join (or leave again)
• See how many foilers plan to ride that departure
• Open it to see who's going by name — or join anonymously
• Set your display name once in Settings; change it any time
• Updates live across devices, so the lineup stays current
• Fully optional and can be turned off in Settings

Also fixed: switching to the next day now always shows the correct departures.

## App Privacy (App Store Connect → App Privacy)

Declare the following data type for the Wave Check-in feature:

- **Data type:** User Content → "Other User Content" (the optional display name)
  - Also consider **Identifiers → User ID** (the anonymous device/account id).
- **Linked to the user?** Yes (it's tied to the anonymous identity).
- **Used for tracking?** No.
- **Purpose:** App Functionality.
- Note: collection is **optional** (users can join anonymously / disable the feature).

No email, no account, no name read from the device is collected.

## Review Notes (optional, App Review → Notes)

Wave Check-in lets users optionally share a self-chosen display name (or stay
anonymous) to indicate they plan to ride a specific ferry-wake departure. Data
is stored on our own backend and auto-deleted after the departure passes. The
feature is optional and can be disabled in Settings. No account or login is
required.
