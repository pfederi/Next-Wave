# App Store Connect — Texts for v4.0.1

## What's New (English)

WHAT'S NEW IN 4.0.1

⛵ Greifensee
Added the boats on Greifensee with 5 stations — Maur, Fällanden, Greifensee, Uster, and Mönchaltorf. Pick them in the list or on the map.

📏 More accurate verified distances
Verified rides now measure distance from speed over time instead of raw GPS points, removing the small overshoot from GPS scatter — your numbers now line up with Foilmotion.

🏆 Verified rides count everywhere
A verified Foilmotion session now counts as a wave on the leaderboard (overall and at its station), in "My Stations", and toward your station and lake badges — plus new verified badges for riding at 3, 5, and 10 stations.

🙈 Cleaner leaderboard
Riders without a name now show as "Anonymous", so ranks always match the list.

Catch you on the water! 🤙

## App Privacy (App Store Connect → App Privacy)

Unchanged from 4.0.0. Verified Rides still stores only aggregate session metrics (distance, speed, ride count) tied to the anonymous user id; the GPX file itself is not stored. 4.0.1 additionally derives the session's nearest boat station from the (locally parsed) track and stores that station reference with the same aggregate metrics — still User Content, linked to the user, not used for tracking, App Functionality only.

## Review Notes (optional, App Review → Notes)

No behavioral change relevant to review. Verified Rides still imports a GPX recorded
in the third-party Foilmotion app via the iOS share / "Open in" flow, parses it
locally, matches the track against the public Swiss boat timetable
(transport.opendata.ch), and stores only aggregate metrics on our backend. 4.0.1
additionally records which boat station a session was closest to, so verified rides
can appear on the per-station leaderboard. No login required; the feature is optional.
