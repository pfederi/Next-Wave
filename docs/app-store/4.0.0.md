## App Privacy (App Store Connect → App Privacy)

In addition to the Wave Check-in data already declared, the Verified Rides feature stores:

- **Data type:** User Content → imported session metrics (aggregate distance, speed, ride count) derived from a user-supplied Foilmotion GPX.
  - Tied to the anonymous user/account id (Identifiers → User ID).
- **Linked to the user?** Yes (tied to the anonymous identity, for cross-device badges).
- **Used for tracking?** No.
- **Purpose:** App Functionality.
- The GPX file itself is not stored — only the computed metrics. Collection is optional (the feature is only used when a user imports a session).

## Review Notes (optional, App Review → Notes)

Verified Rides: users can import a GPX recorded in the third-party Foilmotion app
via the iOS share / "Open in" flow. Next Wave parses it locally, matches the track
against the public Swiss boat timetable (transport.opendata.ch), and stores only
aggregate metrics (distance, top speed, ride count) on our backend to award
"verified" badges. No login is required; the feature is optional. Foilmotion is
referenced with permission and linked from the app's App Store page.
